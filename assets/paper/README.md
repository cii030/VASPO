# Paper assets

These PNG images were exported from the paper assets on 2026-10-15 for display
in the repository README. The source files remain in the paper project.

| Image | Paper source | Export |
|---|---|---|
| `vaspo-overview.png` | `figures/vaspo_overview_teal_coral/vaspo_overview_teal_coral.pdf` | Full figure, 160 dpi |
| `math-results.png` | Table 1 in `VASPO_arxiv_preview.pdf`, page 7; values checked against `tables/main_results.tex` | Table region, 288 dpi |
| `kk-results.png` | Table 2 in `VASPO_arxiv_preview.pdf`, page 7; values checked against `tables/logic_results.tex` | Table region, 288 dpi |
| `training-dynamics.png` | `figures/training_dynamics.pdf`; caption in `figures/training_dynamics.tex` | Full figure, 160 dpi |

Table crops retain all headers, rows, highlighting, and reported values.
Captions and sampling counts are provided in the root README. The curve
image uses training-time avg@16 for AIME and avg@4 for KK, whereas the main
tables use their stated final-evaluation sampling counts.
